# Дерево выражений

Дан математический пример в постфиксной форме (обратная польская запись.). Необходимо построить дерево выражения, где листья - операнды (целые числа), а внутренние узлы - операторы +, −, *, /. После построения дерева нужно вычислить значение выражения с помощью рекурсии.

## Tree_file:

### class TreeNode

Класс узла дерева, имеет три атрибута: значение, левая ветвь и правая ветвь

+ build_expression_tree - функция создающая дерево по выражению

+ evaluate - функция рекурсивно вычисляющая результат по дереву

+ count_operations - функция подсчитывающая колличество операций в дереве (вариативная часть)
