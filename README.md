# Tree_file:

### class TreeNode

Класс узла дерева, имеет три атрибута: значение, левая ветвь и правая ветвь

+ build_expression_tree - функция создающая дерево по выражению

+ evaluate - функция вычисляющая резултат по дереву

+ count_operations - функция подсчитывающая колличество операций в дереве
